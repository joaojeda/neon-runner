# NEON RUNNER

**NEON RUNNER** es un juego de plataformas 2D para navegador donde controlás a VOLT, un robot que atraviesa una ciudad futurista llena de neón. Todo (texturas, sprites, fondo con parallax y sonido) se genera por código, sin imágenes ni librerías externas.

## Características

- Nivel de 200x15 tiles
- Enemigos: robots rodantes y drones
- Bloques de energía golpeables y celdas de energía
- Checkpoint, bandera de meta, vidas, tiempo y puntaje

## Controles

| Acción | Tecla |
|---|---|
| Mover | Flechas o A / D |
| Saltar | ↑ / W / Espacio |
| Turbo | Shift |
| Pausa | P |
| Reiniciar | R |
| Sonido | M |

## Cómo jugarlo

Abrí `index.html` en el navegador, o ejecutá:

```
python -m http.server 8000
```

y entrá a `http://localhost:8000`.
